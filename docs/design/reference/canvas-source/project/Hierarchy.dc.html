Who manages what

Three levels. Each level manages the one below it, within the limits set from above.

Level 1 · whole platform Platform admin
  • •Create, edit and delete organisations
  • •Change the members of any organisation
  • •Manage all user accounts
  • •Optionally limit members and projects per organisation
  • •Move any project to any organisation
Screens 12–14
Level 2 · one organisation Organisation admin
  • •Invite and remove members
  • •Create, import, archive and delete projects
  • •Give members a role per project
  • •Duplicate projects (with a new name) and download them as zip
  • •Move projects to other organisations they also manage
  • •Works within the limits, if any are set
Screens 15–16
Level 3 · one project Project roles
ImplementerRepository, publishing, technical details
EditorEdits content and media, publishes
ViewerReads and previews only
Screen 4

Roles belong to a place, not to a person: someone can be organisation admin in one organisation and editor on a project in another. An organisation admin can open every project in their organisation.

Limits are hard. Any action that would take an organisation over a limit is refused before it runs: inviting, adding a member, a new project, duplicating, moving. The message names the limit and the numbers, and says how to fix it.
